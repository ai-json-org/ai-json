# Changelog

All notable package changes are managed with [Changesets](https://github.com/changesets/changesets).

## 0.1.0 - Draft specification

Initial draft release preparation for the ai.json reference implementation.

- Defines the draft ai.json v1 manifest format and JSON Schema.
- Provides `@ai-json-spec/core` for schema access, parsing, validation, loading, normalization, and readiness analysis.
- Provides `@ai-json-spec/cli` with the `ai-json` binary for `init`, `validate`, `doctor`, and `check`.
- Includes package smoke tests for packed tarballs before publication.

This is a draft release. Breaking changes are possible before a future stable v1 standard.
